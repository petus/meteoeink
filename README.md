# meteoeink - Offline meteostanice s ePaper

Projekt offline meteostanice s ePaper a navíc s extrémně nízkou spotřebou. Detaily naleznete na https://chiptron.cz

## Postup nahrání programu
1. Otevřete stránku http://esp32flasher.chiptron.cz/
2. Stáhněte soubor MeteoEink426.ino.merged.bin z github
3. Zasuňte USB-C kabel do počítače a ESPink-4.26 a připojte jí
4. Zvolte ESP32-S3 a nahrajte na web BIN soubor
5. Nahrajte

## Úpravy zobrazení
Všechny úpravy lze dělat skrze USB-C v počítači na webové stránce http://meteoeink.chiptron.cz/
Nebo na telefonu skrze WiFi

Kompletní návod najdete na chiptron.cz
